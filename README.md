# Projekt gry na przedmiot "Podstawy informatyki"
W celu zbudowania pliku wykonywalnego z poziomu konsoli należy wpisać komendy w następującej kolejności będąc w folderze projektu:
```
cmake -B build
cd build
cmake --build .
```
---
W przypadku użycia Visual Studio IDE należy:
```
1. Mieć zainstalowany pakiet C++
2. Otworzyć folder projektu
3. Wybrać środowisko uruchomieniowe (Windows/WSL) i konfigurację
4. Wybrać plik main.exe
```
